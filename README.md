## Shell Config

### Zsh

Add to `~/.zshrc`:

```
PROMPT='%F{blue}%~%f %F{white}λ%f '
```

### Bash

Add to `~/.bashrc`:

```
PS1='\[\e[34m\]\w\[\e[0m\] \[\e[37m\]λ\[\e[0m\] '
```

Both prompts use:

- Default blue for the current directory
- Default white for the `λ` prompt symbol
- Default terminal foreground for typed commands
